# Персональное портфолио

Честное и лаконичное портфолио начинающего специалиста (студентки колледжа КАСУ по специальности «учитель информатики»). Создано в рамках учебного проекта по скандинавскому стилю (Nordic Lagom Corporate Minimalism).

## Используемые технологии
- HTML5
- CSS3 (Vanilla)
- Vanilla JavaScript

## Запуск
Откройте файл `index.html` в браузере. Все файлы сайта должны находиться в одной папке.
